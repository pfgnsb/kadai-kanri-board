# 画面見取り図


| 項目     | 内容                        |
| ------ | ------------------------- |
| 文書名    | 画面見取り図                    |
| 対象システム | 課題管理ボード（Trello風タスク管理アプリ）  |
| 作成日    | 2026年9月18日                |
| 作成者    | nsb                       |
| 関連資料   | 用語定義書、要件定義書、画面設計書、操作手順書   |
| 目的     | 画面設計書の部品表を読む前に、画面の見た目をつかむ |


言葉の意味は「用語定義書」に従います。部品の番号と動作の詳細は「画面設計書」に従います。

この資料は説明用です。色や余白の正式な約束は画面設計書の「色と見た目の約束」を使います。

---

## 1. 全体のイメージ

ホワイトボードに、灰色の列を横に並べ、白い付箋を貼る画面です。


| 呼び方 | 見た目        | たとえ         |
| --- | ---------- | ----------- |
| ボード | 画面全体。背景は青緑 | ホワイトボード     |
| リスト | 灰色の縦長の箱    | 列           |
| カード | 白い小さな枠     | 付箋。1枚が1件の課題 |


画面は1枚です。カードをクリックしたときだけ、小さな編集画面が重なります。

実物は、Vite の画面（`http://localhost:5173`）を Chrome または Edge で開くと見られます。API（`http://localhost:8080`）と PostgreSQL が動いている必要があります。ログインは不要です。

---

## 2. ボード画面（SCR-01）

起動したあとに、ずっと見える作業場です。

```
  青緑の背景
  ┌─────────────────────────────────────────────────────────────┐
  │ 課題管理                          追加や更新はサーバに…     │  ← 画面上部
  │                                                             │
  │  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐  │
  │  │未着手 削除│  │作業中 削除│  │完了   削除│  │+リストを  │  │
  │  │          │  │          │  │          │  │  追加     │  │
  │  │┌────────┐│  │カードは  │  │カードは  │  │          │  │
  │  ││最初の  ││  │まだあり  │  │まだあり  │  │          │  │
  │  ││カード  ││  │ません    │  │ません    │  │          │  │
  │  ││優先度中││  │          │  │          │  │          │  │
  │  ││        ││  │          │  │          │  │          │  │
  │  │└────────┘│  │          │  │          │  │          │  │
  │  │タスク追加 │  │タスク追加 │  │タスク追加 │  │          │  │
  │  └──────────┘  └──────────┘  └──────────┘  └──────────┘  │
  └─────────────────────────────────────────────────────────────┘
       左の列            真ん中の列         右の列         列を増やす入口
```

図は列の並びのイメージです。初期データのカード枚数は、次の表を正とします。

### 2.1 起動直後


| 場所    | 内容                               |
| ----- | -------------------------------- |
| 左上    | ボード名「課題管理」。見出しであり、書き換えられない |
| 右上    | 「追加や更新はサーバに残ります」。押しても何も起きない |
| 左の列   | リスト名「未着手」。見出しであり、書き換えられない。初期データではカードが2枚 |
| 真ん中の列 | リスト名「作業中」。初期データではカードが1枚 |
| 右の列   | リスト名「完了」。初期データではカードが1枚。期限が今日より前なら赤字 |
| いちばん右 | 「+ リストを追加」                       |




### 2.2 カードに見えるもの

白い枠の中に、次の順で出ます。ない項目は出しません。

1. タイトル
2. 優先度（高は赤、中は黄、低は灰）
3. 期限があるときだけ日付。過ぎていれば赤字
4. 説明文があるときだけ、2行まで。それより長いときは隠す

カード本体をクリックすると、カード編集画面が開きます。  
カードをつまんで、同じ列の好きな位置、または別の列へ置けます。少し動かさずに離すと、移動せずに編集画面が開きます。

リストが増えたときは、横にスクロールして見ます。

## 3. カード編集画面（SCR-02）

カードをクリックすると、ボードの上に小さな窓が重なります。後ろのボードは暗く残ります。

```
  暗いボード（後ろ）
  ┌──────────────────────────────────────┐
  │ 課題管理                              │
  │  （リストとカードは後ろに残る）       │
  │                                      │
  │      ┌────────────────────┐          │
  │      │ カードを編集        │          │
  │      │ タイトル（必須）    │          │
  │      │ 説明文              │          │
  │      │ 優先度   中         │          │
  │      │ 期限（任意）        │          │
  │      │                    │          │
  │      │ [保存] [キャンセル]  [削除] │          │
  │      └────────────────────┘          │
  └──────────────────────────────────────┘
```


| 部品    | 役割                              |
| ----- | ------------------------------- |
| タイトル  | 必須。空のまま保存すると「タイトルを入力してください。」と出す |
| 説明文   | 任意。空でもよい                        |
| 優先度   | 高 / 中 / 低 から1つ                  |
| 期限    | 任意。カレンダーから日付を選ぶ                 |
| 保存    | カードへ反映して閉じる                     |
| キャンセル | 変更せずに閉じる                        |
| 削除    | 確認のあと、カードを消して閉じる                |


周りの暗い部分をクリックするか、Esc を押しても、保存せずに閉じます。

## 4. 画面設計書との対応


| 見取り図        | 画面設計書   |
| ----------- | ------- |
| ボード画面       | SCR-01  |
| カード編集画面     | SCR-02  |
| 画面上部の名前と説明文 | 2.2     |
| リストとカード追加   | 2.3、2.5 |
| カードの中身と移動   | 2.4     |
| 起動直後の並び     | 2.6     |
| 編集画面の入力欄    | 3.2     |
| 色           | 4       |
| 削除の確認文      | 5       |


部品の種類・初期値・最大文字数は画面設計書を正とします。
