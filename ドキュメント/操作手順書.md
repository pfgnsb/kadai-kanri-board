## 1. 準備

画面の認識合わせは、フォルダ直下のモック（`index.html`）を使います。API のひな形は `backend/` の Spring Boot です。

### 1.1 モック画面を開く

1. パソコンで Chrome または Edge を使う
2. フォルダ `アプリケーション` の中にある `index.html` を見つける
3. そのファイルをダブルクリックして開く

ログインは不要です。インターネットに繋がっていなくても使えます。

### 1.2 API サーバ（Spring Boot）を起動する

ボードの本実装（React と PostgreSQL）はこれからなので、いま確認できるのは起動確認用の URL です。JDK の入れ方とフォルダの説明は「Spring Boot バックエンド初期セットアップ」を正とします。

1. JDK 21 が入っていることを確認する
2. `backend` フォルダを開く
3. PowerShell で次を実行する

```powershell
cd backend
$env:JAVA_HOME = "C:\Program Files\Microsoft\jdk-21.0.12.101-hotspot"
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
.\mvnw.cmd spring-boot:run
```

4. ブラウザまたは別の PowerShell で `http://localhost:8080/api/health` を開く
5. `{"status":"ok"}` と出れば起動できている

止めるときは、起動した PowerShell で `Ctrl+C` を押す。

Cursor や PowerShell を開き直したあと、`java` コマンドが通る場合は `JAVA_HOME` の設定は不要です。

## 2. 最初に開いたとき

次の状態で始まります。

- ボード名は「課題管理」
- 左から「未着手」「作業中」「完了」の3列がある
- 「未着手」に、説明用のカードが1枚ある

説明用のカードは、使い方を確認したら削除してかまいません。

## 3. 基本の操作

### 3.1 ボード名を変える

1. 画面左上の「課題管理」をクリックする
2. 新しい名前を入力する
3. 入力欄の外をクリックする

空のままにすると、名前は「課題管理」に戻ります。

### 3.2 カードを追加する

1. 入れたいリストの「+ カードを追加」を押す
2. タイトルを入力する
3. 「追加」を押す

新しくできたカードの優先度は「中」です。説明文と期限は空です。あとから編集できます。

追加をやめるときは「キャンセル」を押します。

### 3.3 カードの内容を直す

1. 直したいカードをクリックする（「左へ」「右へ」以外のところ）
2. タイトル、説明文、優先度、期限を直す
3. 「保存」を押す

タイトルを空のまま保存することはできません。  
保存せずに閉じるときは「キャンセル」を押すか、編集画面の外側をクリックします。

### 3.4 カードを別のリストへ移す

1. カードの「右へ」または「左へ」を押す
2. 隣のリストの一番下へ移る

例：未着手のカードで「右へ」を押すと、作業中へ移ります。  
一番左のリストでは「左へ」は押せません。一番右のリストでは「右へ」は押せません。

### 3.5 カードを削除する

1. 消したいカードをクリックする
2. 「削除」を押す
3. 確認で削除してよいことを選ぶ

### 3.6 リストを追加する

1. 右端の「+ リストを追加」を押す
2. 列の名前を入力する
3. 「追加」を押す

新しいリストは、いちばん右に増えます。

### 3.7 リスト名を変える

1. 列の上部の名前をクリックする
2. 新しい名前を入力する
3. 入力欄の外をクリックする

空の名前にはできません。空にすると、元の名前に戻ります。

### 3.8 リストを削除する

1. 消したいリストの「削除」を押す
2. 確認で削除してよいことを選ぶ

リストを消すと、その中のカードも全部消えます。

## 4. 保存について

モック画面（`index.html`）では、次のとおりです。

- 追加・変更・削除・移動は、その場でブラウザに残ります
- 画面右上に「内容はこのブラウザに自動で保存されます」と出ています
- ページを閉じても、同じパソコンの同じブラウザで開き直すと内容が戻ります

次の場合は、モックの内容が見えなくなります。

- 別のブラウザで開いた
- 別のパソコンで開いた
- ブラウザの保存データを消した

本実装の保存は手元の PostgreSQL です。API のひな形は起動確認までで、まだデータベースにはつながっていません。

## 5. よくある操作の流れ（課題を進める例）

1. 「未着手」に、やることをカードで追加する
2. カードをクリックし、説明文・優先度・期限を入れる
3. 始めたら「右へ」を押して「作業中」へ移す
4. 終わったら、もう一度「右へ」を押して「完了」へ移す

## 6. うまく開かないとき

| 困ったこと | 確認すること |
|---|---|
| 画面が白い、または崩れて見える | `index.html` と同じフォルダに `styles.css` と `app.js` があるか確認する |
| 内容が残っていない | 前回と同じブラウザで開いているか確認する（モックの場合） |
| ファイルを開いても動かない | Chrome または Edge で開き直す |
| `java` が見つからない | JDK 21 が入っているか確認する。必要なら `JAVA_HOME` を JDK のフォルダに向ける |
| `/api/health` が開かない | `backend` で `.\mvnw.cmd spring-boot:run` が動いているか確認する |
