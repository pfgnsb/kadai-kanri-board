## 1. 読み方

| 記号 | 意味 |
|---|---|
| B | ボード |
| L | リスト |
| C | カード |
| S | 保存 |
| 必須 | 空のままでは保存できない |
| 任意 | 空のままでも保存できる |

優先度の内部値は `high` / `medium` / `low`。画面では 高 / 中 / 低 と出す。

---

## 2. ボード

| No. | できること | 詳細 | 画面 |
|---|---|---|---|
| B-1 | ボードを表示する | 起動すると、ボード1枚を表示する。読めないときはエラーを出す | SCR-01 |
| B-2 | ボード名を表示する | 左上に見出しとして出す。書き換えない。初期値は「課題管理」 | SCR-01 |

---

## 3. リスト

| No. | できること | 詳細 | 画面 |
|---|---|---|---|
| L-1 | 初期のリストを出す | API の初期データでは「未着手」「作業中」「完了」の3つ。未着手にカード2枚、作業中に1枚、完了に1枚 | SCR-01 |
| L-2 | リストを追加する | 「リストを追加」から名前を入れて作る。最大30文字。空では作れない | SCR-01 |
| L-3 | リスト名を表示する | 列の上部に見出しとして出す。書き換えない | SCR-01 |
| L-4 | リストを削除する | 削除の前に確認する。中のカードも一緒に消える | SCR-01 |

---

## 4. カード

| No. | できること | 詳細 | 画面 |
|---|---|---|---|
| C-1 | カードを追加する | タイトルを入れて追加する。優先度の初期値は「中」。説明文と期限は空 | SCR-01 |
| C-2 | カードを編集する | カードをクリックして編集画面を開く | SCR-02 |
| C-3 | カードを削除する | 編集画面の「削除」で消す。削除の前に確認する | SCR-02 |
| C-4 | カードを移動する | カードをつまんで、同じリスト内の好きな位置、または別のリストへ置く | SCR-01 |

---

## 5. カードの項目

| 項目 | 必須 / 任意 | 内容 | 対応する機能 |
|---|---|---|---|
| タイトル | 必須 | 短い名前。最大80文字。空では保存できない | C-1、C-2 |
| 説明文 | 任意 | くわしいメモ。最大500文字。空でもよい | C-1、C-2 |
| 優先度 | 必須 | 高 / 中 / 低。追加時の初期値は中 | C-1、C-2 |
| 期限 | 任意 | 日付。空でもよい。今日より前の日付は期限切れとして分かりやすく表示する | C-1、C-2 |

---

## 6. 保存

| No. | できること | 詳細 | 画面 |
|---|---|---|---|
| S-1 | 内容を残す | 追加・更新・削除・移動は Spring Boot の API 経由で PostgreSQL に残す。容量超過の専用画面は出さない | （専用画面なし） |
| S-2 | 開き直して復元する | 同じ PostgreSQL なら、開き直しても前回の内容になる。ボードが無いときは「ボードが見つかりません。」と出す | SCR-01 |

保存先の形は「データベース設計」を正とする。API の技術は「技術スタック」を正とする。初期データの中身は `backend/src/main/resources/data.sql` を正とする。

---

## 7. 例外（機能に関するもの）

| 状況 | 扱い | 関係する機能 |
|---|---|---|
| カードのタイトルが空のまま保存する | 「タイトルを入力してください。」を出し、画面は閉じない | C-2 |
| リスト追加・カード追加で名前が空 | エラーを出し、作らない | L-2、C-1 |
| カードを少し動かさずに離す | 移動せず、クリックとして編集画面を開く | C-2、C-4 |
| リスト削除・カード削除を確認してはいで選ぶ | 取り消せない。中のカードもリスト削除と一緒に消える | L-4、C-3 |
| カードの移動に失敗する | エラーを出し、ボードを読み直す | C-4、S-1 |
| API に繋がらない | 「API に接続できません。サーバが起動しているか確認してください。」を出す | B-1、S-2 |
| ボードが無い | 「ボードが見つかりません。」を出す | B-1、S-2 |
| 別のブラウザで開く | 同じパソコンの同じ API なら、同じ内容になる | S-2 |
| 別のパソコンで開く | そのパソコンの PostgreSQL の内容になる。自動では同期しない | S-2 |
| 編集画面の外側をクリックする、または Esc | 保存せずに閉じる | C-2 |
| 保存容量の超過 | 専用のエラー画面は出さない | S-1 |
