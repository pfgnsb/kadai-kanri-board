## 1. 読み方

| 記号 | 意味 |
|---|---|
| B | ボード |
| L | リスト |
| C | カード |
| S | 保存 |
| 必須 | 空のままでは保存できない |
| 任意 | 空のままでも保存できる |

優先度の内部値は `high` / `medium` / `low`。画面では 高 / 中 / 低 と出す。

---

## 2. ボード

| No. | できること | 詳細 | 画面 |
|---|---|---|---|
| B-1 | ボードを表示する | 起動すると、ボード1枚を表示する | SCR-01 |
| B-2 | ボード名を変更する | 画面左上の名前を書き換える。最大40文字。空にした場合は「課題管理」に戻す | SCR-01 |

---

## 3. リスト

| No. | できること | 詳細 | 画面 |
|---|---|---|---|
| L-1 | 初期のリストを出す | 初めて開いたときは「未着手」「作業中」「完了」の3つを出す | SCR-01 |
| L-2 | リストを追加する | 「リストを追加」から名前を入れて作る。最大30文字 | SCR-01 |
| L-3 | リスト名を変更する | 列の上部の名前を書き換える。最大30文字。空にすると元の名前に戻す | SCR-01 |
| L-4 | リストを削除する | 削除の前に確認する。中のカードも一緒に消える | SCR-01 |

---

## 4. カード

| No. | できること | 詳細 | 画面 |
|---|---|---|---|
| C-1 | カードを追加する | タイトルを入れて追加する。優先度の初期値は「中」。説明文と期限は空 | SCR-01 |
| C-2 | カードを編集する | カードをクリックして編集画面を開く | SCR-02 |
| C-3 | カードを削除する | 編集画面の「削除」で消す。削除の前に確認する | SCR-02 |
| C-4 | カードを移動する | 「左へ」「右へ」で隣のリストの一番下へ移す。端のリストでは、それ以上進めないボタンは押せないようにする | SCR-01 |

---

## 5. カードの項目

| 項目 | 必須 / 任意 | 内容 | 対応する機能 |
|---|---|---|---|
| タイトル | 必須 | 短い名前。最大80文字。空では保存できない | C-1、C-2 |
| 説明文 | 任意 | くわしいメモ。最大500文字。空でもよい | C-1、C-2 |
| 優先度 | 必須 | 高 / 中 / 低。追加時の初期値は中 | C-1、C-2 |
| 期限 | 任意 | 日付。空でもよい。今日より前の日付は期限切れとして分かりやすく表示する | C-1、C-2 |

---

## 6. 保存

| No. | できること | 詳細 | 画面 |
|---|---|---|---|
| S-1 | 内容を残す | 本実装は Spring Boot の API 経由で PostgreSQL に残す。モックは localStorage に自動で残す。保存容量を超えたときの専用画面は出さない | （専用画面なし） |
| S-2 | 開き直して復元する | 本実装は同じデータベースから復元する。モックは同じブラウザで開くと前回の内容を表示する。保存がない、または壊れているときは初期ボード（未着手に説明用カード1枚）を出す | SCR-01 |

保存先の形は「データベース設計」を正とする。モックのキーは `task-board-v1`。API の技術は「技術スタック」を正とする。

---

## 7. 例外（機能に関するもの）

| 状況 | 扱い | 関係する機能 |
|---|---|---|
| カードのタイトルが空のまま保存する | 「タイトルを入力してください。」を出し、画面は閉じない | C-2 |
| ボード名を空にする | 「課題管理」に戻す | B-2 |
| リスト名を空にする | 変更前の名前に戻す | L-3 |
| 一番左で「左へ」、一番右で「右へ」 | ボタンは押せない | C-4 |
| リスト削除・カード削除を確認してはいで選ぶ | 取り消せない。中のカードもリスト削除と一緒に消える | L-4、C-3 |
| 保存がない、または JSON が壊れている | 初期ボードを出す | S-2、L-1 |
| 別のブラウザや別のパソコンで開く | モックは空（初期ボード）になる。本実装は同じ PostgreSQL なら同じ内容 | S-2 |
| 編集画面の外側をクリックする | 保存せずに閉じる | C-2 |
| localStorage の容量超過 | 今回の範囲外。専用のエラー画面は出さない | S-1 |
