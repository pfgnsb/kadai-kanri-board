# 用語定義書

| 項目 | 内容 |
|---|---|
| 文書名 | 用語定義書 |
| 対象システム | 課題管理ボード（Trello風タスク管理アプリ） |
| 作成日 | 2026年9月18日 |
| 作成者 | nsb |
| 目的 | 本システムで使う言葉の意味を揃え、以後の資料と画面で同じ呼び方を使うため |

この資料は、アプリを作る前に決めておく「言葉の辞書」です。同じものを人によって違う名前で呼ばないようにします。

---

## 1. 用語一覧

| No. | 用語 | 意味 | 画面上の呼び方 |
|---|---|---|---|
| 1 | 本システム | 今回作る、一人用のタスク管理アプリ全体のこと | 課題管理ボード |
| 2 | ユーザー | 本システムを操作する人。今回の利用者は nsb 一人。提出先は説明の相手であり、アプリの利用者ではない | （ログインはない） |
| 3 | 画面 | ユーザーが見て操作する表示。メインはボード画面1枚。カード編集時だけ小さな画面が重なる | ボード画面、カード編集画面 |
| 4 | ボード | 列とカードをまとめて置く、作業全体の台のこと | 画面全体 |
| 5 | ボード名 | ボードの名前 | 画面左上の名前。初期値は「課題管理」 |
| 6 | リスト | カードを入れる縦の列。作業の進み具合を表す | 列。初期値は「未着手」「作業中」「完了」 |
| 7 | リスト名 | リストの名前 | 各列の上部 |
| 8 | カード | 1つのやることを書いた小さな枠 | カード |
| 9 | タイトル | カードの短い名前。必ず入れる | タイトル（必須） |
| 10 | 説明文 | カードのくわしいメモ。空でもよい | 説明文 |
| 11 | 優先度 | そのカードをどれだけ急ぐか | 高 / 中 / 低。追加時の初期値は「中」 |
| 12 | 期限 | カードを終わらせたい日付。空でもよい | 期限（任意） |
| 13 | 必須 | 空のままでは保存できない項目 | タイトル |
| 14 | 任意 | 空のままでも保存できる項目 | 説明文、期限 |
| 15 | 追加 | 新しいリストやカードを作ること | 「カードを追加」「リストを追加」 |
| 16 | 編集 | すでにある名前や内容を直すこと | カードをクリックして開く編集画面 |
| 17 | 削除 | リストやカードを消すこと。消したリストの中のカードも消える | 「削除」 |
| 18 | 移動 | カードを隣のリストへ移すこと | 「左へ」「右へ」 |
| 19 | 保存 | 入力した内容を残し、あとから同じ状態で開けるようにすること | 編集画面の「保存」。ボードの内容は自動でも残る |
| 20 | ブラウザ | インターネットのページを見るソフト（Chrome や Edge など） | 本システムを開く場所 |
| 21 | 自動保存 | ユーザーが特別な操作をしなくても、内容がブラウザに残ること | 「内容はこのブラウザに自動で保存されます」 |
| 22 | 初期状態 | 初めて開いたときの状態 | 列が3つあり、説明用のカードが1枚ある |
| 23 | 未着手 | まだ始めていない作業を置くリスト | 左の列 |
| 24 | 作業中 | 今やっている作業を置くリスト | 真ん中の列 |
| 25 | 完了 | 終わった作業を置くリスト | 右の列 |
| 26 | 編集画面 | カードの内容を直すために重なって開く小さな画面 | 「カードを編集」 |
| 27 | 確認 | 削除の前に、本当に消すか聞くこと | 「削除しますか？」 |
| 28 | 一人用 | 自分だけが使い、他の人と同時に共有しないこと | 本システムの前提 |
| 29 | 利用者 | アプリを実際に操作する人。今回は nsb 一人 | （ログインはない） |
| 30 | 説明先 | 資料を読んで確認する提出先。アプリの利用者ではない | （画面には出ない） |
| 31 | ユースフロー | やりたいことを達成する道筋 | 要件定義書のフロー図 |
| 32 | 操作フロー | 画面上のクリックなど、手を動かす手順 | 要件定義書のフロー図 |
| 33 | 画面遷移 | 見える画面が変わること。今回は SCR-01 と SCR-02 の行き来 | ボード画面とカード編集画面 |
| 34 | 非機能要件 | 速さ・保存の残り方・動かす環境など、機能以外の約束 | （画面には出ない） |
| 35 | localStorage | ブラウザがパソコン内に文字データを残す仕組み。キーは task-board-v1 | 「内容はこのブラウザに自動で保存されます」 |
| 36 | 論理データモデル | ボード・リスト・カードの関係を、表の形で整理したもの。いまの保存は JSON 1件 | （画面には出ない） |
| 37 | ER図 | 論理データモデルを図にしたもの。boards・lists・cards の3つ | （画面には出ない） |

## 2. 似ている言葉の使い分け

| 呼び方 | 使うとき |
|---|---|
| リスト | 資料の中では、この呼び方を正式名称とする |
| 列 | 画面の説明で、見た目を伝えるときにも使ってよい。リストと同じものを指す |
| カード | やることを表す枠。付箋のようなもの |
| タスク | 日常会話では「やること」の意味で使ってよいが、画面上の名前はカードに統一する |
| 利用者 | アプリを操作する人。今回は nsb 一人 |
| 説明先 | 資料を読む提出先。アプリの利用者ではない |
| ユースフロー | やりたいことを達成する道筋 |
| 操作フロー | 画面上のクリックなど、手を動かす手順 |
| 画面遷移 | SCR-01 と SCR-02 の行き来。「左へ」「右へ」は画面遷移ではない |

---

## 3. 優先度の定義

| 値 | 意味 | 目安 |
|---|---|---|
| 高 | 先にやる必要がある | 赤い表示 |
| 中 | 普通の急ぎ具合 | 黄色い表示。新しく作ったカードの初期値 |
| 低 | 後回しにできる | 灰色の表示 |

---

## 4. この資料の使い方

- 要件定義書、画面の説明、プログラムの説明では、この表の用語を使う
- 新しい言葉が必要になったら、この表に足してから使う
- 同じ意味の言葉を、資料ごとに別の名前で書かない
